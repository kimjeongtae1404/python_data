# Python 초급 팀프로젝트 5종
각 팀은 주제 하나를 선택합니다. 주제별 과제안내.md와 데이터사전.csv를 먼저 읽고 starter.py를 실행하세요. 첫 실행은 CSV 읽기만 완성되어 있습니다.
1. LOT 검색: 문자열 검색과 딕셔너리 집계.
2. 센서 점검: 숫자 변환과 범위 검사.
3. 생산불량 집계: 수량 검증과 그룹 합계. 첫 팀프로젝트에 추천.
4. 정지시간 집계: datetime 실습 포함. 다른 주제보다 날짜 계산이 한 단계 추가됨.
5. 생산파일 통합: 같은 형식의 여러 파일과 전역 중복 제거.
각 주제는 4일 28시간 기준이며 필수 범위를 먼저 완성합니다. 데이터는 모두 합성 자료입니다.
