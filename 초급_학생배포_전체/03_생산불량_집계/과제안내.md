# 생산·불량 실적 집계 프로그램

## 목표와 처리 규칙
각 행은 생산과 전수검사가 끝난 생산실적입니다. 검사 대상이 생산량과 같으므로 생산량=양품+불량입니다. 부분검사·미검사·재검사는 없습니다.
필수 기능: 수량 오류·중복 제거, 제품별 및 설비별 생산량·양품·불량 합계, 불량률 계산, 제품명 검색. 결과가 없는 제품은 안내합니다.
검사 규칙: 세 수량은 빈 값이 없는 정수여야 합니다. 생산량>0, 양품·불량≥0, 생산량=양품+불량. 정상 날짜·제품·설비명을 제공합니다. 동일 record_id 중복은 한 번만 사용합니다.
불량률(%)=그룹의 불량 수 합계÷그룹의 생산 수 합계×100. 개별 행의 불량률을 단순 평균하지 않습니다. 합계가 0인 그룹은 미산출입니다. 비율만 소수 둘째 자리로 표시하세요.
필수 결과: clean_data.csv, error_data.csv, summary.csv(제품별 생산·양품·불량·불량률%), equipment_summary.csv(설비별 같은 지표).
파일 연결과 검사 분모 설계는 이미 단순화했습니다. 그래프나 날짜별 집계는 선택입니다.

## 사용하는 문법과 도구
Python의 변수, 조건문, 반복문, 리스트, 딕셔너리, 함수, 간단한 클래스와 csv 모듈을 사용합니다. 외부 패키지 설치, pandas, SQL, DB, 웹앱은 필요 없습니다. 화면은 print 출력이면 충분합니다. 그래프와 메뉴는 선택입니다.
모든 데이터는 교육용 합성 데이터입니다. CSV는 UTF-8 BOM이며 읽을 때 encoding="utf-8-sig", newline=""을 지정합니다. 소스코드와 데이터 폴더는 같은 프로젝트 폴더 안에 두세요.

## 기본 작업 순서
원본은 수정하지 않습니다. 파일 읽기 → 오류 검사 → 정상 데이터와 오류 데이터 분리 → 요약/검색 → 결과 CSV 저장 순서로 구현합니다. 중복은 ID와 전체 값이 같은 행 하나만 남깁니다. 이 데이터의 중복 ID는 모두 전체 값도 같습니다. 서로 다른 값의 같은 ID 처리와 원천 데이터 수정은 확장 범위입니다.
값을 임의 추정해서 채우지 않습니다. 아래 주제별 규칙에 따라 오류를 기록하고 집계에서 제외합니다. 오류 개수는 종류별 규칙 경고 수가 아니라 제외된 행 수를 기준으로 셉니다. 한 행에 오류가 둘 이상이면 이유를 함께 적어도 됩니다.
명세에 없는 코드 별칭, 날짜 단위 혼재, 버전 수정본, 실시간 수집은 없습니다. 일부 정상값이 높은 경우를 오류와 혼동하지 마세요.

## 클래스 사용 범위
Manager 클래스 하나에 원본 행, 정상 행, 오류 행을 보관하고 load_data(), validate_data(), summarize_data() 정도로 나누면 충분합니다. 상속·추상 클래스·디자인 패턴은 요구하지 않습니다. 먼저 함수로 동작하게 만든 다음 관련 기능을 클래스로 묶어도 됩니다.

## 제출물 / 필수와 선택 구분
필수: Python 실행 파일, 정상/오류/요약 CSV, 오류 처리 규칙 1쪽, 실행 안내, 검증표, 5~7분 시연. 클래스 하나 이상과 함수 분리를 활용합니다. 발표 자료는 간단한 문서 또는 슬라이드 자유입니다.
선택: 검색 메뉴 또는 간단한 그래프 중 하나. 필수 기능이 끝나기 전에는 확장하지 않습니다.
검증표에는 정상 예시, 오류 예시, 전체 합계 확인, 없는 검색값, 같은 파일 재실행 결과를 기록합니다. 실행할 때 정상/오류 리스트를 초기화하고 결과 파일은 덮어써도 됩니다. 누적 적재나 DB 트랜잭션은 필요 없습니다.
평가: 파일 처리·저장 20, 오류 처리 25, 핵심 검색/집계 30, 함수·클래스·가독성 15, 검증·설명 10점. 화려한 화면보다 정확한 결과와 본인 코드 설명을 평가합니다.
